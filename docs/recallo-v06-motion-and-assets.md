## 1. 设计基调

毛球（原创角色）与整套视觉遵守四个关键词：

- **珊瑚橙**：主行动色与角色主色，温暖但不刺眼；
- **奶油白**：纸面底色，卡片与页面都落在奶油色系上；
- **铅笔线**：描边带轻微手绘感，圆角允许轻微不规则；
- **轻颗粒**：极轻的纸面颗粒纹理，只做质感，不影响可读性。

只借鉴成熟卡牌产品的**揭晓节奏**（期待 → 光迹 → 停稳 → 揭示）与**卡面层级**（稀有度徽标 / 掌握状态 / 内容区 / 证据区），不复刻、不描摹、不导出其任何美术资产。

设计检索参考 [Agent UI Atlas](https://github.com/starvingarc/agent-ui-atlas)，组合比例锁定为 50% Kawaii Minimal、30% Hand-Drawn Doodle / Sketch Line Art、20% High-End Soft UI / Fluid Motion。Atlas 只用于提取留白、材质、线条和动效原则；其链接项目、品牌、截图和素材仍受各自许可证约束。

## 2. 动效时间轴

### 2.1 首页与召回入口

| 动作 | 参数 |
| --- | --- |
| 毛球待机 | 8–14 秒最多一次微动作；用户操作、低电量或 Reduce Motion 开启后停止 |
| 轻点毛球 | 280–420ms 情境回应，只改变姿态或提示，不发放奖励 |
| 主入口轻压 | `:active` 时缩放到约 0.97，松开后用可打断弹性缓动回到原位 |
| 点击 / 上拖召回 | 点击明确按钮或把卡叠上拖 24–36pt；拖动中卡片倾斜 clamp 在 ±4° |
| 手势取消 | 未达到阈值松手，卡叠在 200ms 内弹回，不创建会话、不改变调度 |

### 2.2 召回过场

首张完整过场约 1450ms：

| 阶段 | 时间窗 | 内容 |
| --- | --- | --- |
| 起势 | 0–250ms | 封存卡从卡叠升起，倾斜 ≤ ±4° |
| 光迹 | 250–750ms | 一道按稀有度着色的光迹扫过：R 铅笔灰、SR 珊瑚橙、SSR 暖金；只表达内容潜力，不表达概率 |
| 停稳 | 750–1250ms | 卡面归正、落定，轻微回弹 |
| 亮标 | 1250–1450ms | 稀有度徽标与掌握状态淡入 |
| 进入回忆 | 1450ms | 自动进入回忆卡面；任意时刻可点“跳过过场”直接落地 |

用户在检查点选择继续后，后续卡使用约 700ms 的短过场，只保留毛球取卡、卡面升起、停稳和提示；不重复完整光迹仪式。

红线：过场中不出现转盘、卡包、十连、概率数字、保底计数或“差点抽到”的伪悬念。

### 2.3 语义揭示

| 动作 | 参数 |
| --- | --- |
| 语义擦开 | 首次唤醒时，承重语义 span 被铅笔涂鸦层覆盖；拖擦覆盖率达到约 45% 后完整揭示，无像素残留 |
| 点击揭示 | 点击（轻点）遮盖区域同样揭示，260ms 内淡入完整语义；键盘 Enter / Space 等价，方向键可分段擦开 |
| 直接揭示 | 始终保留文字按钮入口，服务 VoiceOver 与运动障碍用户 |
| 复现变式 | 后续复现改为判断（对 / 不对）或选择（少量选项），选择后立即给出对错与解释 |

### 2.4 反馈与入册

| 动作 | 参数 |
| --- | --- |
| 三档反馈 | 只有“记得 / 模糊 / 忘记”三个按钮，配色克制（柔绿 / 暖金 / 灰红），无连击、无爆闪 |
| 毛球点击反应 | 点击毛球触发一次 280–420ms 的挤压回弹（squash & stretch），可伴随一句轮换提示 |
| 入册 | 卡片修复上色并被毛球收回，一次完成；庆祝只此一次，不循环播放 |
| 下次复习 | 反馈真实写入调度并展示：忘记 → 明天优先，模糊 → 2 天后，记得 → 4 天后（演示数值，正式由调度器决定） |
| 检查点 | 当前卡收好后露出下一张真实卡边缘；用户选择“继续召回”或“先收好”，系统不自动连播 |

### 2.5 无假进度

- 禁止假进度条、假百分比、伪造的“加载中”动画；
- 分析等待页只展示真实阶段文案（如“识别画面与文字证据…”）或静态说明；
- 所有等待都必须可被真实完成或真实失败终止。

## 3. 状态机

### 3.1 召回会话状态机

```text
                ┌─────────────┐
                │    home     │ 今日 Tab：单一召回入口
                └──────┬──────┘
              点击 / 上拖 24–36pt
                       ▼
                ┌─────────────┐   跳过 / Reduce Motion
                │  summoning  │ ──────────────────────┐
                └──────┬──────┘                       │
              ~1450ms 过场完成                        │
                       ▼                              ▼
                ┌─────────────┐                ┌─────────────┐
                │   recall    │ ◄──────────────│  (直达卡面)  │
                │ masked /    │                └─────────────┘
                │ judgment /  │
                │ choice      │
                └──────┬──────┘
        擦开 ≥45% / 点击揭示 / 直接揭示 / 作答变式
                       ▼
                ┌─────────────┐
                │  revealed   │ 完整语义 + 解释 + 来源证据
                └──────┬──────┘
            记得 / 模糊 / 忘记
                       ▼
                ┌─────────────┐
                │  assessing  │ 保存结果 + 真实下次复习时间
                └──────┬──────┘
                       ▼
                ┌─────────────┐
                │ checkpoint  │ 下一张边缘 + 继续召回 / 先收好
                └─────────────┘
                    │       │
                 继续       收好
                    ▼       ▼
              summoning   stowing → home
```

任意时刻退出：持久化当前卡、稳定阶段、刮开覆盖率和反馈标识；下次恢复时不重复提交结果，也不重新播放完整抽取。`judgment` / `choice` 变式只在卡片已完成首次唤醒后出现；`masked_semantic` 只出现一次。

## 4. Reduce Motion 降级

触发源：`prefers-reduced-motion: reduce` 媒体查询（跟随系统，演示页在我的 Tab 中展示当前状态）。

| 标准行为 | 降级行为 |
| --- | --- |
| 1450ms / 700ms 召回过场 | 180ms 缩放与淡入，直接落在回忆卡面 |
| 入口与检查点弹性回弹 | 仅透明度 / 选中态变化，无旋转位移 |
| 上拖手势倾斜 | 保留手势阈值，取消倾斜动画 |
| 擦开粒子 / 涂鸦剥落 | 遮盖层直接淡出，阈值逻辑不变 |
| 毛球 280–420ms 挤压 | 静态表情切换，无缩放动画 |
| 光迹扫过 | 稀有度徽标直接呈现 |
| 全局滚动与转场 | `animation-duration` / `transition-duration` 收敛到接近 0 |

降级只移除“动”，不移除“态”：状态推进、阈值、结果页和调度完全一样。

## 5. 角色姿态（毛球）

毛球是用户的情境伙伴：奶油白毛发、珊瑚色微光、深青色铅笔描边与轻颗粒阴影。它不发放奖励，只通过姿态解释当前发生的认知动作。

| 姿态 | 使用场景 | 表现 |
| --- | --- | --- |
| `idle` | 今日默认 | 站立、伸懒腰、发呆、喝水或看书的低频轮换 |
| `reacting` | 用户轻点毛球 | 280–420ms 挤压回弹或害羞 / 偷笑，不发奖励 |
| `turning` | 开始召回 | 转头看向知识文件夹 |
| `rummaging` | 选卡阶段 | 小跑到文件夹并翻找，动作可被跳过 |
| `carrying` | 卡片升起 | 抱着代码原生卡片返回 |
| `watching` | 用户主动回忆 | 安静注视；停顿较久后轻微侧头，不催促 |
| `acknowledging` | 反馈为记得 / 模糊 | 点赞、小跳或侧头，只播放一次 |
| `thinking` | 反馈为忘记 / 内容处理中 | 思考或陪伴坐下，不用惩罚色 |
| `sleeping` | 无可召回内容 / 低频夜间状态 | 静态打盹或极慢呼吸 |
| `farewell` | 用户选择先收好 | 把卡放回文件夹并挥手 |

实现约束：优先复用仓库现有透明 PNG 和用户提供并授权的素材。SwiftUI / CSS 可通过缩放、位移、镜像、倾斜、遮挡和代码原生卡片 / 文件夹把一张姿态组合为多个情境；不为“风格统一”重复生成角色。

## 6. 反赌博与无社交边界

动效与素材不得越过以下边界：

1. 不制造概率悬念：光迹只表达已定卡片的内容潜力，卡在进入过场前已被调度器选定；
2. 不用递增刺激：没有连抽加速、没有“再来一发”式催促，每张之间都由用户在检查点手动推进；
3. 不用损失厌恶：没有倒计时、 streak、保底、错过提示；忘记不降级、不摧毁卡片；
4. 不做社交比较：无排行榜、无分享战绩、无好友资产展示；知识库与收藏册仅自己可见；
5. 不用成就压迫：无签到、无每日任务墙；统计页只展示真实数字；
6. 不用虚假反馈：无假进度、无伪装的“AI 正在努力思考”循环动画；
7. 庆祝克制：单次、短促、可跳过，永远服务“我想起来了”这个认知时刻，而不是“我抽到了什么”。

## 7. 素材授权策略

白名单（完整登记与 bundled / considered 状态见 [`asset-provenance.md`](./asset-provenance.md)）：

| 素材 | 许可证 | 允许范围 |
| --- | --- | --- |
| Pow `1.0.6` | MIT | iOS 运行时的少量跳跃、闪光与粒子反馈；精确锁定版本 |
| Kenney Particle Pack `1.1` | CC0 | 只使用 `star_04.png`、`circle_05.png`、`smoke_06.png` |
| Phosphor Icons Core `2b75f3a` | MIT | Web 端只使用 5 个原始 SVG，保留许可证 |

硬性规则：

- 素材处理先分类为 `reuse_as_is`、`reuse_with_crop_or_recolor`、`rebuild_in_code`、`generate_only_if_missing`；
- 固定顺序为仓库现有素材 → 用户提供并授权素材 → 已登记开源素材 → 关键缺口生成；
- 用户提供 JPEG 可以直接裁切、去背景、调色和组合；派生文件必须登记原文件、处理方式与校验值；
- MVP 不引入 Lottie / Rive 及任何动效运行时；
- 不下载或使用授权不清的素材；拿不准就不进仓库；
- 不得宣称使用了未实际导入的素材——登记文档与实际文件、依赖锁定一一对应；
- 角色与卡面默认原创；白名单只覆盖动效依赖、粒子与图标三类补充；
- 借鉴仅限节奏与层级：任何第三方游戏的图、音效、字体、卡面设计都不进仓库。
